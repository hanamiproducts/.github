# .github

Organisation profile for [Hanami Products](https://github.com/hanamiproducts) on GitHub.

- `profile/README.md` is the text shown on <https://github.com/hanamiproducts>. GitHub reads it from this public repo, named `.github`.
- `profile/hanami-blossom.png` is the logo it shows (240 px, made from the studio's blossom icon).

Edit the profile here, open a pull request and merge it; GitHub shows the new text right away.

Keep it in line with the brand-voice guide: plain words, no medical claims, no invented numbers, nothing planned described as built, and no server, port or admin details.
